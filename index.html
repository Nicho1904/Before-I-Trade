Categories & questions

Each category needs a name and at least one question. Each question needs three answer options — they're scored 2 (best) down to 0 automatically, top to bottom.

Verdict thresholds & wording

Thresholds are set as a percentage of the total possible score, so they still work no matter how many questions you have. Use {weak} anywhere you want your weakest category's note inserted — it'll read in-sentence, lowercase. Use {Weak} for a capitalized, sentence-starting version.
